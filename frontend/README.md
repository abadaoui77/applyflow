# Frontend ApplyFlow

Interface React, Vite, React Router et Material UI.

Consulter le [README du projet](../README.md) pour l’installation et la configuration des API.

Depuis ce dossier :

```sh
npm ci
npm run dev
npm run lint
npm run build
```

Copier .env.example vers .env.local et renseigner VITE_AUTH_API_URL et VITE_APPLICATION_API_URL avant le lancement.
Le résultat de compilation est généré dans dist.
